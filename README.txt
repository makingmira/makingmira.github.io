MAKING MIRA — WEBSITE DESIGN PREVIEW
====================================

What this is:
A design preview of the new makingmira.com single-page site.
This is one self-contained HTML file — all fonts, styles, and
animations are embedded, so it works with no internet connection
and nothing to install.

How to view it:
1. Unzip this folder anywhere.
2. Double-click PREVIEW-single-file.html
   (it will open in your web browser).

Notes:
- All images are abstract placeholders (line-drawn shapes).
  Real jewelry photos replace them in the final build.
- The page adapts to light or dark mode based on your system setting.
- The contact form is visual-only in this preview.
- The final site will be delivered as separate HTML / CSS / JS
  files for hosting on GitHub Pages.
